Example Extension

This is the English user documentation published with the TurboWarp Extension Template.

Runnable sample / 実行できるサンプル

Open Hello World in TurboWarp Editor · Download hello-world.sb3

Allow the extension, then click the green flag. Greeting shows “Hello, world!”. Change the name in the hello block and run again.

拡張の読み込みを許可し、緑の旗を押すとGreeting変数に挨拶が表示されます。名前を変更して再実行できます。

Template requirement

Repositories created from this template should replace this page with English documentation for their extension and keep the GitHub Pages URL in extensionConfig.docsURI.

They should also replace the example blockIconURI with a meaningful, self-contained SVG icon encoded as data:image/svg+xml;base64,....
